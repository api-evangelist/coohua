# Coohua (酷划在线)

> Coohua — 北京酷划在线网络技术有限公司 — is a Beijing mobile advertising company founded in
> March 2014 that built China's incentive- and lock-screen-advertising category. Its flagship
> apps, Coohua Lockscreen (酷划锁屏) and Tao News / NewsEarn (淘新闻), paid users cash for
> unlocking their screens and reading content, and monetized that attention for advertisers
> across internet, finance, automotive and e-commerce verticals. Backed by Qiming Venture
> Partners and SIG (US$20M Series B, May 2015). Coohua publishes **no public API, developer
> portal, SDK, or machine-readable specification**. This file is generated by API Evangelist
> from the company's own public pages and its GitHub organization; it is not published by
> Coohua.

## Status of the developer surface

- No OpenAPI, Swagger, GraphQL, AsyncAPI, MCP or A2A surface exists on any Coohua host.
- Probed and missed: `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`,
  `/api-docs`, `/docs`, `/redoc`, `/graphql`, `/llms.txt` and the full `/.well-known/` set —
  across `www.coohua.com`, `coohua.com`, `www.coohua.cn`, `api.coohua.cn`, `open.coohua.cn`,
  `developer.coohua.cn` and `docs.coohua.cn`. See `well-known/coohua-well-known.yml`.
- The `coohua.cn` domain is dead: the apex has no A record, and every subdomain is a DNS
  wildcard to 39.106.94.60 answering openresty HTTP 500 on every path.
- The `coohua.com` site root now serves an unrelated product page (海南耀游奇迹 / 猪猪世界,
  filed by 海南耀天网络技术有限公司 under 琼ICP备20000955号-2). The original Coohua corporate
  pages survive as individual files beneath that root and still carry Coohua's own
  京ICP备14013745号 filing.
- Advertising business is transacted by sales email (sale@coohua.com), not by API.

## Code

- [github.com/coohua-dev](https://github.com/coohua-dev): Coohua's GitHub organization, 8 public
  repositories. Holds CocoaPods private spec repos (`CHSpecs`, `Specs`) for the iOS modules

  the podspecs resolve to `gitlab.coohua.com`, which is not reachable publicly, so none of the
  pods are installable by a third party.
